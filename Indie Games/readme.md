**Indie Games**
--

El siguiente Python Notebook, realiza diferentes análisis de los juegos cuyo género es *indie*. 
El dataset utilizado fue exportado del siguiente enlace de Kaggle
[**"Backloggd" Indie Games Dataset (48,000+ Titles)**](https://www.kaggle.com/datasets/pravar11/backloggd-indie-games-dataset-48000-titles).

**Instrucciones**

Para ejecutar el Python Notebook tiene que ejecutar el siguiente comando para instalar las librerías mencionadas en el archivo de texto (requirements.txt):

```pip install requirements.txt```
