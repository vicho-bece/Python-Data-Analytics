**Movie Rating**
--

El siguiente Python Notebook, realiza un análisis de las valoraciones numéricas de cada película registrada en el siguiente dataset en Kaggle
[**TMDB Popular Movies**](https://www.kaggle.com/datasets/thedevastator/exploring-popular-movies-using-tmdb-data).

**Instrucciones**

Para ejecutar el Python Notebook tiene que ejecutar el siguiente comando para instalar las librerías mencionadas en el archivo de texto (requirements.txt):

```pip install requirements.txt```
