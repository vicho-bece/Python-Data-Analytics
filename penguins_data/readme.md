**Clustering: Penguins Data**
--

El Notebook Python implementa modelos de *Clustering* para encontrar agrupaciones o similitudes dentro el dataset de pingüinos, 
utilizando la información de las caracteristicas físicas de un pingüino (pico, aleta, cuerpo y sexo).

Los siguientes modelos y modos a desarrollar en el Notebook son:
- *K-Means* (*kmeans++* , *random* y *miniBatch*)
- *DBSCAN*

El dataset que se utilizo en los modelos fue extraido del dataset de Kaggle 
denominado [**Clustering Penguins Species**](https://www.kaggle.com/datasets/youssefaboelwafa/clustering-penguins-species).

**Instrucciones**
--

Para compilar y ejecutar este Notebook, abre una consola de comando y ejecuta el siguiente código:

```pip install requirements.txt```

Esto permite instalar las bibliotecas para manipular los datos, generar los modelos de *clustering* y graficar la data y los resultados obtenidos.
